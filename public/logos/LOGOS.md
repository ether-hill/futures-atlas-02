# /public/logos — sources

- claude, openai, huggingface, nextjs, vercel, threejs, p5js, react, tailwindcss, d3: generated from the [simple-icons](https://simpleicons.org) dataset (CC0), fill=currentColor.
- midjourney, kling, sora, runway, stability, flux, meta, mistral, qwen, deepseek, ollama, deepmind, anthropic, cohere, microsoft: from [@lobehub/icons-static-svg](https://github.com/lobehub/lobe-icons) (MIT), fill=currentColor.
- seedance / nanobanana / veo: parent-brand marks (ByteDance / Gemini / Google) from the same lobehub set — the models have no dedicated marks.
- makemode: the brand's own `favicon.svg` (the triad: triangle / square / circle), redrawn as paths so it can render mono or in its three brand colours.
- frond-studio.png: Frond Studio's wordmark, white on transparent, used as a CSS mask over `currentColor` so it holds in both themes.
- The Quantum Delta NL lockup (shown on the About page for the Centre for Quantum and Society) is inlined in `src/components/about/Collaborators.tsx`, taken from qdnl.nl.
- Trademarks remain with their owners; used nominatively in the stack inventory.
